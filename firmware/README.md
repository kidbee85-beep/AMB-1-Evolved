# AMB-1 Evolved E1

Independent FM-1 firmware derived from Bunkai Wolf A1 (source commit a3f7cb3), AMB-1 and Felucca. GPL-3.0-only; upstream notices retained.

64 sound presets, 32 musical themes, 20 scales, five inherited generator variations. Same seven-page AMB interface and A1 palette. See EVOLVED-TEST-STATUS.txt for exact scope, tested behavior and hardware limits.

Build with `JIELI_TOOLCHAIN=... AC79_SDK=... bash build.sh`. This project is separate from Bunkai Wolf A3. Identity FM-1_7080001, independent project magic/format; old projects are not imported. SAVE replaces the shared device project object.
